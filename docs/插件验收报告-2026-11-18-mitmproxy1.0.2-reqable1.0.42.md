## 三、根因定位（单因果链）

**2026-11-17 连续两次固件升级重置了 docker/plugins 分区数据并导致容器运行时停摆**：

固件升级 → docker/plugins 分区空间归零 + containerd 被禁用（enabled=no，无工作磁盘）→ 应用市场拉不到任何数据（两个抓包插件连列表都看不到）→ 插件既装不了也跑不了。

注意：「Docker 未运行」与「市场为空」是同一条因果链的上下游，**不是两个独立缺陷**。磁盘本身不是瓶颈（sda7 尚有约 2.7GB 可用），问题出在分区未分配给 docker/plugins。

## 六、遗留问题与建议
