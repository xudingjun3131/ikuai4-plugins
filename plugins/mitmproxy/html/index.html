mitmweb 界面, 即下方嵌入的窗口
使用步骤：1. 点启动引擎（可勾“开机自启”）；2. 点下载 CA 证书，在要抓包的设备上安装并信任（iOS: 设置→通用→关于本机→证书信任；Android: 用户证书）；3. 把该设备的 Wi-Fi 代理手动设为 路由器IP:{{ proxyPort }}；4. 在下方 mitmweb 界面里查看解密后的请求/响应，可改写、可断点、可脚本。
说明：本插件自带完整 Python 运行时（约 100MB，装在数据卷，不占系统分区）；HTTPS 解密需要客户端信任 CA，未信任的域名会握手失败；v1 仅支持显式代理（手动设代理），透明引流后续版本加。
