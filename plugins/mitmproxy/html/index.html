透明拦截的 TCP 端口(默认 80,443; UDP443/QUIC 自动阻断)
透明抓包（无需客户端设置）：勾选上面的"抓包总开关" + 在设备列表里勾上要抓的设备，该设备的 80/443 流量会被 iptables 精确 REDIRECT 到本插件解密（只影响勾选的设备，其它设备与路由器自身完全不受影响）。
显式抓包（旧方式仍可用）：把设备 Wi-Fi 代理手动设为 路由器IP:{{ proxyPort }}，不依赖 iptables 规则。
注意：关闭总开关或停止引擎时 iptables 规则会自动撤除；HTTPS 解密需要客户端安装并信任 CA（见下方"下载 CA 证书"）。

使用步骤

1. 点启动引擎（可勾"开机自启"）；2. 点下载 CA 证书，在要抓包的设备上安装并信任（iOS: 设置→通用→关于本机→证书信任；Android: 用户证书）；3. 抓包方式二选一：透明——开"抓包总开关"并勾选设备；显式——设备代理手动设 路由器IP:{{ proxyPort }}；4. 在下方 mitmweb 界面里查看解密后的请求/响应，可改写、可断点、可脚本。
说明：本插件自带完整 Python 运行时（约 100MB，装在数据卷，不占系统分区）；HTTPS 解密需要客户端信任 CA，未信任的域名会握手失败。
